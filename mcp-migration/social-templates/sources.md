# Sources

Gallery URLs to collect template patterns from. One per line, with optional
hints after `|` (expected format, category focus).

Filled by the maintainer; consumed by the Capture stage (PROTOCOL.md §1).
If a gallery blocks automation, save preview screenshots manually into
`refs/` (any filename, .png/.jpg) and list the directory here instead —
the pipeline only needs the local files.

## Format

```
https://www.canva.com/templates/s/instagram-story/ | story, mixed categories
https://www.canva.com/templates/s/carousel/        | carousel, educational focus
refs/manual-batch-1/                               | manually saved previews
```
